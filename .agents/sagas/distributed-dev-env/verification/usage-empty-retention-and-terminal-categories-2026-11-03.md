# Empty quota retention and refused terminal categories

A successful Claude envelope can contain no quota rows. Such a result must
remain unavailable without replacing an earlier, account-bound last report or
borrowing its timestamps. Retain the most recent usable capture alongside the
latest empty envelope in the existing two-capture journal bound. Assembly keeps
the original usable observation and receipt, records the actual empty attempt,
and withholds its current quota. Zero is a reported value, not an empty result.
An empty-only history must never acquire a last-good reference. This change
does not restore captures already evicted from a running journal.

The scheduled diagnostic on the signed ae21128 operator did not match the fixed
ten-frame spinner set. That private acceptance candidate remains held. Refine
only the refusal reason using standard Unicode properties: encoding/replacement,
combining marks, spacing and format characters; other characters retain the
existing generic refusal. Every unsupported character still returns ErrCapture.
There are still exactly five diagnostic fields, with no literal character,
codepoint, text, count, hash or extra payload. New categories are Cursor-only,
builtin-only and require an empty clientVersion.

Unicode categories use the Go standard library's
[unicode tables](https://pkg.go.dev/unicode@go1.27.3) and
[UTF8 decoder](https://pkg.go.dev/unicode/utf8@go1.27.3#DecodeRune). They are diagnostic partitions, not acceptance sets or evidence of
the actual rejected character. No new guessed allowlist is introduced. Tainted
screen recovery is not implemented: the pinned renderer's complete-clear and
absolute-reanchor sequence has not been qualified. Partial erasure, relative
movement, malformed encoding, unknown width and partial escape sequences cannot
authorize input or capture.

Validation must include stateful usable-to-empty-to-empty restart retention,
empty-only history, genuine zero rows, original timestamps and binding, current
value withholding, strict diagnostics, fragmented UTF8, unchanged refusals and
owned synthetic subprocesses. No provider command, credential operation, retry,
journal reset, clock change or expiry extension is part of source validation.
Independent current review and CI precede merge and signed publication. Source,
installation and actual three-provider/API/agent/UI acceptance remain separate.

The capture command uses its existing Keeper-dependent normal client context.
The retention fix prevents loss of history; it does not establish or repair the
upstream reason a valid envelope has no quota. Credential fencing is unchanged.

Focused stateful tests first failed (0.078 seconds) and category tests first
failed (0.003 seconds). The empty-array case exposed an additional partial
availability classification; both null and empty arrays now project unavailable.
The focused regression suites pass (collector 0.109 seconds, helper 0.006 seconds),
including owned PTY encoding refusal and real zero data. Full race validation
and current independent review remain required before delivery.
