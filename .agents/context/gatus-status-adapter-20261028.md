# Gatus current-check snapshot adapter — source-only

This pure adapter accepts the Gatus endpoint status API's array with an explicit caller-supplied observation time and source reference. Both are assertions, not authenticated provenance. It makes no network request and has no collector, CLI, UI, runtime configuration or deployment. Its result is a current endpoint-check snapshot, not notification, page, Pushover or delivery history. Retention completeness, incident duration and recurrence remain Unknown.

The adapter keeps stable case-sensitive endpoint key, name, group, and only the latest check by actual UTC instant: timestamp, explicit success, optional HTTP status and optional integer nanosecond duration. Missing, empty or null results mean success is Unknown; null or missing key, success or timestamp is invalid. Optional absent status/duration stay Unknown rather than becoming zero; explicitly supplied zero stays zero. Same-instant exact replays, including equivalent timestamp offsets, are accepted; differing other payload fields at the same instant fail the entire snapshot. Duplicate endpoint keys, ambiguous structural key spelling, duplicate JSON keys, malformed data and bounds violations also fail closed as Unavailable. Unknown fields are bounded and discarded. Hostnames, errors, condition text and links are not projected. Name/group/source text receives control cleanup and heuristic redaction; this is not a guarantee against every possible secret in caller-provided text.

Source parser defaults, not production SLOs: 2 MiB input, nesting depth 16, 1,000 endpoint records, 4,000 elements per list and 4,000 total results, 1,000 members per object, 8,192 bytes per string or key, and 512 bytes for the source reference. A valid empty array is an available observation of zero endpoints, not a claim of historical absence.

Shape reference: upstream Gatus v5.37.0 [endpoint status](https://github.com/TwiN/gatus/blob/v5.37.0/config/endpoint/status.go) and [result](https://github.com/TwiN/gatus/blob/v5.37.0/config/endpoint/result.go); version and bounded live discovery were reported by the coordinator, not retrieved by this source test. The finite fixtures are synthetic. No installed or parent-tool acceptance is claimed.
